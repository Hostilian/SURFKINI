# SURFKINI — Third-Party Open-Source Attributions

SURFKINI contains mathematical algorithms, netcode architectures, and performance templates adapted from the following open-source projects:

1. **Valve Source SDK 2013** (`ValveSoftware/source-sdk-2013`)
   - Surface friction, `PM_AirAccelerate`, and `PM_ClipVelocity` physics math.

2. **Godot 4 Source Engine Movement** (`EricXu1728/Godot4SourceEngineMovement`)
   - Clean-room Quake/Source engine movement math model (MIT License).

3. **Fast-Paced Multiplayer Netcode** (Gabriel Gambetta)
   - Client-side prediction, server reconciliation, and lag compensation rewind buffer patterns (MIT / CC-BY 4.0).

4. **C++ Object Pool Template** (`OpenPool/cpp-object-pool`)
   - High-performance memory recycling template (MIT License).

5. **Momentum Mod / SurfTimer** (`momentum-mod/game`)
   - Speedometer UI layout and u/s display conventions (BSD-3-Clause).
